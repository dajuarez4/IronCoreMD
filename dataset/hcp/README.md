# HCP Fe dataset

This directory contains the compressed HCP Quantum ESPRESSO trajectories at
5000 K, selected QE inputs, a structural phase trace, and the current
paramagnetic/noncollinear preparation work.

The top-level `a_*_5000K.npz` archives are the portable inputs used by the ML
and visualization scripts. `hcp_paramagnetic_p_vs_v.csv` and its SVG companion
record the third-order Birch-Murnaghan curve generated by
`codes/birch_murnaghan_hcp_pm.py`.

`hcp_mag/` documents the difficult noncollinear HCP campaign. Its
`recommended/` directory contains a staged unconstrained-preconvergence and
constrained-MD sequence based on the successful BCC settings. See the local
READMEs before launching those calculations.

Generated TDEP workspaces are intentionally not tracked here.
