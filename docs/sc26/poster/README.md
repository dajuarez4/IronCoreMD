# SC26 research-poster draft

This package contains an editable 48 x 36 inch landscape UTEP-style `baposter`, a print-ready PDF preview, a PNG preview, the figures used in the draft, a 150-word abstract, and the required description of planned updates.

## Build

The package includes `baposter.cls`, so it can be uploaded directly to Overleaf without installing a separate class. Compile with pdfLaTeX:

```bash
pdflatex poster.tex
pdflatex poster.tex
```

Place the official UTEP logo at `utep-logo.png` before compiling. Until then, both the LaTeX source and preview show a labeled placeholder.

The bundled class is from the upstream [mloesch/baposter](https://github.com/mloesch/baposter) repository.

The repository machine did not have a TeX engine installed, so `poster_preview.pdf` and `poster_preview.png` are generated by the included `make_poster_preview.py`. The LaTeX source remains the authoritative editable version.

Edit `metadata.tex` before submission. The 48 x 36 inch draft fits within the SC display board of 48 x 78 inches.
